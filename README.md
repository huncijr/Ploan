# Klinx — Dynamic Terminal & Web UI Theming for AI CLIs

Type `/klinx "make it cyberpunk"` in any AI CLI — your terminal wallpaper, theme, opacity, OS desktop background, and web dashboard transform instantly.

---

## What is Klinx?

A universal plugin/extension that intercepts `/klinx` or `/customizable` slash commands in AI CLIs (Claude Code, Grok, Aider, Open Interpreter, OpenCode) and dynamically restyles your entire development environment — terminal, OS wallpaper, and Web UI — to match any theme you describe.
